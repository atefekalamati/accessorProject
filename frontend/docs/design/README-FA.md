# بسته‌ی تحویل فرانت کالیا

این بسته همه‌ی چیزی است که برای ساختن فرانت لازم داری: طراحی نهایی صفحه‌ها، لوگو، رنگ‌ها و فونت‌ها، و یک پرامپت شروع برای Claude Code.

## چه چیزی کجاست؟

| پوشه یا فایل | چیست؟ |
|---|---|
| `HANDOFF.md` | مشخصات کامل فرانت به انگلیسی، مخصوص Claude Code: صفحه‌ها، حالت‌ها، قوانین قیمت و موجودی، دسترس‌پذیری |
| `design/pages/` | ۱۲ صفحه‌ی طراحی‌شده (دسکتاپ و موبایل). HTML معمولی‌اند و اندازه و رنگ دقیق هر جزء داخلشان است |
| `design-system/` | راهنمای برند، فایل رنگ‌ها و اندازه‌ها (`tokens.json`) و همان مقدارها به‌صورت متغیرهای CSS (`tokens.css`) |
| `brand/` | لوگوی روبانی با زمینه‌ی شفاف، به‌علاوه‌ی نسخه‌ی روشن تک‌رنگ |
| `CLAUDE-CODE-PROMPT.md` | پرامپت شروع فاز فرانت |

## چطور شروع کنی؟

1. فایل zip را باز کن.
2. محتوای پوشه‌ی `kalea-frontend-handoff` را در ریپو، داخل `docs/design/` بگذار.
3. یک branch تازه بساز (مثلاً `frontend/phase-1`)؛ یعنی یک شاخه‌ی جدا تا کار فرانت روی کد اصلی اثر نگذارد.
4. Claude Code را در یک session تازه باز کن و پرامپت داخل `CLAUDE-CODE-PROMPT.md` را بده.
5. Claude Code اول فقط برنامه را نشان می‌دهد و فهرست کتابخانه‌هایی که می‌خواهد نصب کند. تأیید را جدا تایپ کن.
6. کار در ۵ بسته جلو می‌رود و هر بسته با یک PR تمام می‌شود. مثل بک‌اند، PR را خودت merge کن.

## چند نکته‌ی مهم

- **مرجع‌ها ترتیب دارند.** اگر طراحی با API فرق داشت، `openapi.json` معتبر است. Claude Code باید اختلاف را گزارش کند، نه اینکه حدس بزند.
- **قیمت را فقط بک‌اند حساب می‌کند.** فرانت فقط عددی را که API می‌دهد نمایش می‌دهد.
- **برای دیدن طراحی‌ها:** فایل‌های `.dc.html` در مرورگر کامل نمایش داده نمی‌شوند. برای دیدن نسخه‌ی تعاملی، بوم «KALÉA — Final Design» را در Claude باز کن و Play را بزن.
- **صفحه‌هایی که هنوز طراحی نشده‌اند:**
  - لیست دسته در موبایل
  - نتیجه‌ی پرداخت
  - فرم آدرس
  - صفحه‌ی ۴۰۴

  این صفحه‌ها در بسته‌ی آخر با همین رنگ‌ها و الگوها ساخته می‌شوند.
